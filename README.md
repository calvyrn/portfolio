**Tiers**
- **Simple:** fast one- or two-page sites with click-to-call, a clear offer and a short form.
- **Medium:** sites with a working feature: online booking, ordering, intake, client portal or property search.
- **High-end 3D:** interactive 3D and animation (Three.js, GSAP) for brands that want to stand out.

All businesses shown are fictional and labelled as example concepts. New projects are added every week.
